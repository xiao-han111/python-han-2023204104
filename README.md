# PID温度控制仿真系统

## 项目简介

PID温度控制仿真系统是一个基于Python和PyQt5开发的温度控制仿真教学软件，支持多种控制策略，包括普通PID、单回路PID、前馈+反馈控制、串级PID和串级+前馈控制。

## 技术栈

- **开发语言**：Python 3.10+
- **UI框架**：PyQt5
- **绘图库**：pyqtgraph
- **运行环境**：Windows 10/11
- **开发工具**：VS Code

## 功能特点

- **多种控制策略**：支持5种控制策略的无缝切换
  - 普通PID(无限幅)
  - 单回路PID（带抗饱和）
  - 前馈+反馈控制
  - 串级PID控制
  - 串级+前馈控制

- **实时波形显示**：实时显示设定值、过程值、控制量、干扰和误差

- **参数调整**：支持实时调整PID参数，包括串级PID的内外环参数

- **干扰功能**：可配置振幅和持续时间的方波干扰

- **历史数据**：自动记录仿真数据，支持历史曲线查询和导出

- **用户管理**：支持管理员和普通用户角色，具有不同的权限

- **异常处理**：完善的异常捕获机制，确保程序不闪退

## 环境配置

### 1. 安装Python

请确保安装了Python 3.10或更高版本。可以从[Python官网](https://www.python.org/downloads/)下载并安装。

### 2. 安装依赖

在项目根目录下运行以下命令安装依赖：

```bash
pip install -r requirements.txt
```

### 3. 依赖包说明

- PyQt5：GUI框架
- pyqtgraph：波形显示
- pandas：数据处理
- openpyxl：Excel导出

## 运行方法

### 1. 启动程序

在项目根目录下运行以下命令：

```bash
python src/main.py
```

### 2. 登录系统

使用以下默认账号登录：

- **管理员**：`admin` / `admin123`
- **普通用户**：`user` / `user123`

### 3. 开始仿真

1. 选择控制策略
2. 设置设定温度
3. 调整PID参数（可选）
4. 点击"开始仿真"按钮
5. 观察波形变化
6. 可点击"施加方波干扰"按钮测试系统对干扰的响应

## 控制策略说明

### 1. 普通PID(无限幅)
- 纯PID算法，无抗积分饱和
- 无输出限幅（教学演示用）
- 可观察积分饱和现象

### 2. 单回路PID控制（带抗饱和）
- 位置式PID算法
- 条件积分抗饱和（误差方向有利于退出饱和时累积积分）
- 输出限幅 [-30, 30]

### 3. 前馈+反馈控制
- 前馈补偿可测干扰
- 静态前馈增益：Gff = -Kd/Kp = -0.5
- 反馈部分使用PID

### 4. 串级PID控制
- 外环：控制被控对象最终输出
- 内环：控制第一惯性环节输出（中间变量）
- 外环反馈：第二环节输出+干扰
- 内环反馈：第一环节输出

### 5. 串级+前馈控制
- 串级结构基础上叠加前馈补偿
- 前馈作用于内环输出（最终控制量）

## 项目结构

```

├── src/                # 源代码
│   ├── control/        # 控制算法

│   ├── user/           # 用户管理
│   ├── utils/          # 工具类
│   ├── config.py       # 全局配置
│   ├── exception.py    # 异常处理
```

## 数据导出

- 仿真结束后，数据会自动保存到 `data` 目录
- 可以在"功能"菜单中打开"历史曲线"窗口，查询和导出历史数据
- 支持导出Excel和CSV格式

## 打包发布

运行 `build_exe.py` 脚本可打包为单文件EXE：

```bash
python build_exe.py
```

打包后的文件将位于 `dist` 目录中。

## 注意事项

1. 确保安装了所有依赖包
2. 运行时请保持网络连接（首次运行需要加载PyQt5资源）
3. 如需修改系统参数，请在 `config.py` 文件中进行调整
4. 仿真数据会自动保存到 `data` 目录，请确保该目录存在且有写入权限
